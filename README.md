---

## 📌 Sobre o Projeto

O **Cadastro de Pedidos** é um projeto de estudos focado na construção de um backend para gerenciamento e processamento de pedidos. A aplicação utiliza o banco de dados **H2 em memória**, permitindo um ambiente de desenvolvimento rápido e sem necessidade de instalações complexas de banco de dados locais.

### 💡 Principais Aprendizados
* Configuração do ecossistema Spring Boot via `application.properties`
* Uso do console Web do H2 para visualização e testes de dados em memória
* Mapeamento de entidades e rotas da aplicação

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java 26
* **Framework:** Spring Boot
* **Banco de Dados:** H2 Database (In-Memory)
* **Gerenciador de Dependências:** Gradle
